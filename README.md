# Bash CTF Cracker & Decoder

A lightweight Bash tool designed for Capture The Flag (CTF) competitions to decode Base64 and crack MD5/SHA-256 hashes using a wordlist.

## Features
- Base64 encoding and decoding support.
- MD5 hash cracking via wordlists.
- SHA-256 hash cracking via wordlists.

## Installation & Usage

```bash
# 1. Clone the repository
git clone [https://github.com/YOUR_USERNAME/bash-ctf-cracker.git](https://github.com/YOUR_USERNAME/bash-ctf-cracker.git)

# 2. Go to the directory
cd bash-ctf-cracker

# 3. Give execution permissions
chmod +x hashcracker.sh

# 4. Run the tool
./hashcracker.sh
